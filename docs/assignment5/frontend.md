# Heuristic Evaluation

# Usability

- Accessibility: I think my design for right now is very good for accessibility. The large and easy to read font makes visual impairments less of a problem, and allows easier interaction with the app.

- Pleasantness: My color palette is pleasant in that it is unoffensive. I only use orange and grey tones on the website, but perhaps this is too boring to have much of a visual color appeal. Will research how to complement these colors and see if I can find a solution that is both relaxing to the eye and more appealing.

# Physical

- Fitt's Law: In the same line as the accessibility, it is also easy to get to and click aspects of the interface because of the large form factor of most of the buttons.

- Accelerators: I don't actually have many accelerators in my UI design. This is something I have to work on. I have a sidebar but not much else.

# Linguistic

- Information Scent: Perhaps my travelling concept violates this. It is not entirely clear what the travelling button does. I think perhaps I either need to change the wording or make some kind of information hover function where people can elarn what it does.

- Consistency: I try to use the same type of interface with each concept. The forums look the same, even when they are characteristic of only one group. I think I could probably give visuals for the group functionality that are more consistent.
